# Import Bookmarks, Logins, History, & Extensions from Your Previous Browser

*This article applies to Arc on **macOS** and **Windows***

## Import from Your Previous Browser

- On Arc for macOS **Arc > Import from Another Browser** in the Mac Menu Bar and on Arc for Windows go to the **Arc menu > Import from Another Browser**.
- Select the Browser you'd like to Import from
- Hit the Next Button to continue selecting which **Bookmarks** to import. Imported bookmarks show up as [Pinned Tabs](https://resources.arc.net/hc/en-us/articles/19231060187159-Pinned-Tabs-Tabs-you-want-to-stick-around) in Arc

![CleanShot 2023-11-26 at 10.14.33@2x.png](/hc/article_attachments/19335105393815)

## What data gets imported?

Different data will be imported, depending on the browser you choose. You can see a list of what's imported after selecting your browser. Arc can import data like bookmarks, passwords, history and extensions.

![CleanShot 2023-11-26 at 10.17.41.gif](/hc/article_attachments/19335096839575)

## Which Browsers Can I Import From?

Arc supports importing from the following browsers:

- Chrome

- Safari

- Firefox

- Brave

- Edge

- Opera

- Opera GX

- Vivaldi
