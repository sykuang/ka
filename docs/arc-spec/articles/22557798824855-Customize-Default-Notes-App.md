# Customize Default Notes App

*This article applies to Arc for **macOS**, but not Arc for **Windows**.*

Arc streamlines your note-taking process by allowing you to set a default notes application that best suits your workflow. Now that [Arc Notes has been phased out](https://resources.arc.net/hc/en-us/articles/19233788518039-Notes-Quickly-Jot-to-an-Arc-Note-or-Your-Favorite-Notes-App), we strongly encourage you to change your default notes app, which will allow you to continue creating notes in **Notion**, **Google Docs**, **Word** or **Confluence**.

## Change Your Default Notes App

Instead of using Arc Notes, you can use another note-taking service via the Command Bar.

1. Go to **Arc** > **Settings** > **Profiles** and use the dropdown under "**New Documents**" to select another platform as your default notes app.

![](/hc/article_attachments/22557798819095)
2. Use **Command+T** and type “**New Note**” to begin taking notes on the platform you selected.
