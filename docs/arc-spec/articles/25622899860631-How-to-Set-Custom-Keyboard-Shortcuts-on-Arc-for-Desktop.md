# How to Set Custom Keyboard Shortcuts on Arc for Desktop

You can edit or remap keyboard shortcuts on Arc for **macOS** in Settings:

1. Open Settings from the Mac Menu Bar by clicking Arc > Settings or use the Command-Comma shortcut
2. Click *Shortcuts*
3. Select a Shortcut from the list
4. Press the keys of your preferred shortcut combination.
Tip! Use a modifier key to start your shortcut (e.g. shift, control, option, or command).
Learn more about [setting custom keyboard shortcuts from Jenamarie.](https://youtu.be/zcOysbiQd2A?si=PJ0mqr_x4q4K7mUc)

Custom Keyboard shortcuts are not currently supported on Arc for **Windows**.
