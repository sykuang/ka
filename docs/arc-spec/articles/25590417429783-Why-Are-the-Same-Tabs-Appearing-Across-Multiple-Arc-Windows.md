# Why Are the Same Tabs Appearing Across Multiple Arc Windows?

*This article applies to Arc on **macOS** and **Windows.***

When you create a new tab in a [Space](https://resources.arc.net/hc/en-us/articles/19228064149143-Spaces-Distinct-Browsing-Areas), that tab will appear in the same Space across Arc Windows. This way you’ll never lose a tab in a Space, regardless of the window.

## Blank Windows

For a completely separate Arc window, use *Blank windows*.

To create a new *Blank Window:*

1. Open the Command Bar:
  - on macOS, press Command-T
  - on Windows, press Control-T
2. Enter the text "new blank window" and click the option when it appears
You can also simply drag a tab out of your Sidebar to create a new *Blank Window*.
