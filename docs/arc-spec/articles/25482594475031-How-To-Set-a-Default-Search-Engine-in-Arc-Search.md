# How To Set a Default Search Engine in Arc Search

*This article applies to Arc Search for **iOS** & **Android**.*

By default, your search engine is set to **[Browse for Me](https://arc.net/l/quote/nxlbfohw)** in Arc Search for iOS and Android. **Browse for Me** is our AI-powered search that creates a personalized webpage tailored to your search request.

To change the default search engine in Arc Search:

1. Tap the Tab Switcher at the bottom left corner of the Arc Search app
2. Tap the Settings icon (⚙️)
3. Tap Search Engine
4. Select a new default Search Engine from the list:
  - Google
  - Bing
  - DuckDuckGo
  - Ecosia
  - Perplexity
  - Kagi
