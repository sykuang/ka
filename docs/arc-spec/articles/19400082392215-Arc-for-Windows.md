# Arc for Windows

Arc for Windows is now available for the general public! To download Arc for Windows, head to [arc.net/download](https://arc.net/download) or you can download Arc from the [Microsoft Store](https://apps.microsoft.com/store/detail/XPFMDW72VHTTX9?ocid=pdpshare)! 🎉

Please note, these are the only approved methods of installation and during the installation process we won’t ask for your device or other passwords.
