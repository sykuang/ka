# Does Arc for Desktop Have Internal Two-Factor Authentication?

Arc for desktop doesn’t currently offer Two-Factor authentication (2FA) for saved passwords, but this may change in the future.

However, if you use a password manager that has an option for 2FA, you can still use it in Arc, but you’ll want to make sure you authorize Arc on your password manager.

As an example, [here's how you can set-up 2FA in 1Password](https://support.1password.com/one-time-passwords/), a password manager we recommend.
