# How Do I use iCloud Passwords or Passkeys on Arc for Desktop?

You can easily access your iCloud passwords or passkeys in Arc for desktop by installing the [iCloud Password extension from the Chrome Web Store](https://chromewebstore.google.com/detail/icloud-passwords/pejdijmoenmkgeppbflobdenhhabjlaj).
