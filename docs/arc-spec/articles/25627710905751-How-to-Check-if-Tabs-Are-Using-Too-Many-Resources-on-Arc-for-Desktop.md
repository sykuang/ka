# How to Check if Tabs Are Using Too Many Resources on Arc for Desktop

You can check if certain tabs are using too much of your computer's resources by checking the Task Manager. From the Task Manager, you can also choose to end a process and free up resources on your computer.

To check the Task Manager and end processes on Arc for desktop:

## macOS

1. Go to Help > Troubleshooting > Open Task Manager in the Mac Menu Bar.
2. Identify any resource-heavy Arc tasks that you want to stop in the Task Manager. Note that the Task Manager displays any tasks currently running, each task’s Memory Footprint, and how much CPU each task is using.
3. Click a task to select it, and then click the End Process button to stop the task.

## Windows

1. Go to Arc Menu > Help > Troubleshooting > Open Task Manager
2. Identify any resource-heavy Arc tasks that you want to stop in the Task Manager. Note that the Task Manager displays any tasks currently running, each task’s Memory Footprint, and how much CPU each task is using.
3. Click a task to select it, and then click the End Process button to stop the task.
**Note**: Screenshots of your Task Manager can be helpful when submitting [bug reports](https://resources.arc.net/hc/en-us/requests/new) related to performance.
