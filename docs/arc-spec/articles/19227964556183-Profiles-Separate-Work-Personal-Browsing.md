# Profiles: Separate Work & Personal Browsing

*This article applies to Arc on **macOS** and **Windows**.*

Profiles allow you to scope Logins, Cookies, Browsing History, [Archive](https://resources.arc.net/hc/en-us/articles/19228855311127) timing, and other settings to one or multiple Spaces.

A common use for Profiles is separating Work data from Personal data.

****

## What’s included in a Profile?

- [Archive settings](https://resources.arc.net/hc/en-us/articles/19228855311127)

- Authentication (logins, passwords, autofill)
- Browser History
- Cache / Cookies
- Default Browser Selection
- Favorites
- Extensions
- Settings in arc://settings (such as Language or Download Preferences)

## How to add a Profile to a Space:

![Screenshot 2024-01-18 at 12.42.30 PM.png](/hc/article_attachments/20677900113815)

- Hover over your Space Title and click the ... on macOS or Edit on Windows then hover over "Profile"
- Select an existing Profile or Create a new one
- New profiles are empty containers without authentication or history. As you start logging in and navigating, the Profile will retain that data.

***To remove a Profile from your Space***, hover over your Space Title and click "Edit" and select Profile > Default.

For now, **Profiles do not sync across devices** (but we hope to build this soon!). Your Spaces and Tabs will still sync across devices, even if they belong to a Profile.\

## How to Delete a Profile

#### **macOS**

You can remove an unused or unwanted Profile by heading to** Arc > Settings > Profiles** in the Mac menu bar, clicking the Profile you want to delete, and then clicking “Delete Profile.”

#### **Windows**

You can remove an unused or unwanted Profile by heading to** Arc menu > Settings >** then clicking the Profile you want to delete, and then clicking “Delete Profile.”

On both macOS and Windows you won’t be able to click the “Delete” button until you’ve removed that Profile from all your Spaces.
