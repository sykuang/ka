# How Do I Find My Saved Passwords in Arc for Desktop?

1. Open Settings
  - On **macOS** go to the Mac Menu Bar, click Arc > Settings or use the Command-Comma shortcut
  - On **Windows** go to Arc menu > Settings or use the Control-Comma shortcut
2. Go to Profiles and select a Profile to check any associated passwords
3. Click "Password" to view Arc’s Chromium settings
4. Review your saved passwords in the Arc Password Manager for the selected Profile
5. Click a website from the list to view or edit a password
