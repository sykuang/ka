# Troubleshoot or Report a Problem in Arc

**Arc is being sunset on December 22, 2026**. After that date, you won't be able to sign in to or use Arc. Please note that we will deactivate all Arc accounts on December 22. Once an account is deactivated, we will delete user personal data associated with the account within 30 days. Not to worry! Many of the Arc features you love live on in Dia, and you can bring your Arc setup along in just a few clicks. To see the full timeline, read [Arc Sunset: Key Dates and What to Expect](https://resources.arc.net/hc/en-us/articles/44412972248471). To make the switch, read [Move from Arc to Dia](https://resources.arc.net/hc/en-us/articles/44413129117591).

If something isn't working in Arc for macOS or Windows, try the quick fixes below. If they don't help, you can report the problem using the chat button in the corner of this page until Arc is sunset on December 22, 2026.

**Please note that until Arc is sunset, we're only looking into larger problems that affect many members, like Arc crashing or not opening.** We're no longer fixing smaller bugs or accepting feedback or feature requests for Arc.

## Make sure Arc is up to date

Many problems are already fixed in the latest version of Arc. To learn how to update, read [**Update Arc for Desktop**](https://resources.arc.net/hc/en-us/articles/21489650267031).

## Some content is missing from a webpage

An ad blocker may be blocking part of the page. Arc for macOS installs the uBlock Origin ad blocker by default. To turn it off for a site:

1. Select the Site Controls icon next to the URL bar.
2. Select the red uBlock Origin shield.
3. Select the large power button to turn off uBlock Origin for that site.
4. Refresh the page.

## Arc feels slow

### Turn off extensions you don't use

Extensions can slow Arc down. To turn off extensions you don't use often, press **Command + T** on macOS or **Control + T** on Windows, type **Manage Extensions**, and turn off any extensions you don't need.

### Close tabs that are using a lot of memory

A single tab can sometimes use a lot of memory and slow down your whole computer. To find it, open Arc's Task Manager:

- On macOS, navigate to **Help > Troubleshooting > Open Task Manager** in the Mac menu bar.
- On Windows, open the Arc menu and select **Help > Open Task Manager**.
Select any tab that's using a lot of memory, then select **End process**.

## How do I report a problem with Arc?

Select the chat button in the corner of this page and tell us what's happening. It helps to include what you were doing when the problem started and whether it happens every time. Please note that we use reports to spot larger problems that affect many members, so we may not be able to fix a problem that only happens on your device.

Your build info tells us which version of Arc you're using, which helps us look into your problem. Sharing it is optional.

- On macOS, navigate to **Help > Troubleshooting > Copy Build Info** in the Mac menu bar.
- On Windows, open the Arc menu and select **Help > Copy Build Info**.
Then paste it into your chat with us.

### Send a performance trace

If Arc is still slow or using a lot of memory after you've tried the steps above, you can record a performance trace and send it to us.

On macOS:

1. Navigate to **Help > Troubleshooting > Record Trace** in the Mac menu bar.
2. Choose how long to record from the dropdown menu.
3. Describe the issue you're seeing.
4. Close any tabs you don't want included in the trace.
5. Select **Start Tracing**.
On Windows:

1. Open the Arc menu and select **Help > Send Performance Trace**.
2. Choose how long to record from the dropdown menu.
3. Describe the issue you're seeing.
4. Close any tabs you don't want included in the trace.
5. Select **Start Tracing**.
A notification lets you know when the trace starts and when it's finished.

### What's included in a performance trace?

A performance trace includes a list of your open tabs and their URLs, and the actions you take while it records, like switching tabs or scrolling. We don't receive the content of your tabs or your cookies.

## Can I still send feedback or feature requests for Arc?

No. As Arc is being sunset, we're no longer accepting feedback or feature requests. Many Arc favorites are already in Dia. To see which ones, read [**Arc Sunset: Frequently Asked Questions**](https://resources.arc.net/hc/en-us/articles/44413577819159). If there's something you'd love to see in Dia, you can tell the Dia team from inside Dia:

- On macOS, navigate to **Help > Chat with Support** in the Mac menu bar.
- On Windows, open the Dia app menu and select **Help > Chat with support**.
